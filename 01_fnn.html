01처음 오신 분께 — 이 도면을 3줄로

조수 하루가 직접 그려서 건네는 첫 번째 딥러닝 설계도면입니다. 아홉 장 가운데 가장 단순하고, 나머지 여덟 장이 모두 이 도면의 부품을 빌려 씁니다.

무엇을숫자 몇 개를 받아 곱하고 더한 뒤 살짝 구부려서, 다음 층으로 넘기기를 몇 번 되풀이하는 장치입니다.
왜 중요한가신호가 앞으로만 흐르는 가장 기본 꼴이라, CNN·RNN·트랜스포머 안에도 이 장치가 부품으로 들어 있습니다.
업무에서는고객 정보로 해지 여부를 판정하거나, 집 조건으로 가격을 예측하는 표 데이터 일에 바로 씁니다.

코드나 수식을 몰라도 됩니다. 수식은 옆에서 동료가 한 조각씩 대신 물어봐 줍니다.

이 도면에 나오는 영어 약어 풀이
FNN
Feedforward Neural Network, 피드포워드(앞먹임) 신경망. 신호가 앞으로만 흐른다는 뜻

04부품 명세 — 한 번 흐를 때 일어나는 일

도면의 번호를 따라 신호가 한 번 지나가는 길입니다. 회색 줄은 하루가 현장에서 건넬 말이에요.

①입력 — 표의 한 줄을 넣는다

고객 한 명의 나이·사용 기간·민원 횟수처럼, 표의 한 줄을 숫자 몇 개로 넣습니다. 이 숫자 하나하나를 특성(feature)이라고 불러요.

"단위가 너무 다르면(나이 40, 매출 4,000만) 먼저 비슷한 크기로 맞춰 둘게요."

②가중합 — 중요도를 곱해 더한다

입력마다 중요도(가중치 w)를 곱해서 모두 더하고, 기준을 옮기는 값(편향 b)을 더합니다. 결과를 z라고 부릅니다.

"민원 횟수에 가중치를 크게 주면, 민원이 많은 고객일수록 z가 커져요."

③활성화 — 살짝 구부린다

z를 활성화 함수에 넣어 구부립니다. 구부리지 않으면 층을 아무리 쌓아도 직선 하나와 같아져요. 은닉층에는 주로 ReLU(음수는 0, 양수는 그대로)를 씁니다.

"구부리는 부품이 있어야 '민원 3번까지는 괜찮다가 4번부터 위험' 같은 꺾인 규칙을 배워요."

④출력 — 예측값 ŷ를 낸다

마지막 층이 답을 냅니다. "해지할까?"처럼 확률이 필요하면 0~1로 눌러 주는 시그모이드를, 가격처럼 아무 숫자나 나와야 하면 그대로 두는 선형 출력을 씁니다.

"ŷ(와이 햇)은 '모델이 짐작한 y'라는 뜻이에요. 모자를 씌워서 정답 y와 구분해요."

⑤학습 — 틀린 만큼 가중치를 고친다

예측 ŷ와 정답 y의 차이(손실)를 재고, 손실이 줄어드는 쪽으로 가중치를 조금씩 고칩니다. 고칠 방향은 역전파, 고치는 걸음은 경사하강법이 정해요.

"한 번에 크게 고치지 않고, 수천 번 조금씩 고쳐요."

05왜 이 설계를 쓰나 · 수식은 동료가 대신 물어봅니다

박사회사에 고객 표가 있고 "다음 달에 해지할 고객"을 미리 알고 싶다고 해 봅시다. 사람이 규칙을 하나하나 쓰기엔 조건이 너무 많아요. 그럴 때 이 도면이 처음 꺼내는 설계입니다.

왜 이 설계를 쓰나

  1. 문제 상황 · 입력 여러 개가 얽혀서 답을 정하는데, 그 규칙을 사람이 다 적을 수 없습니다.
  2. 앞 방법의 한계 · 직선 하나(선형 회귀·로지스틱 회귀)는 "어느 선을 넘으면 위험"처럼 꺾이거나 휘는 규칙을 못 그립니다.
  3. 해법 · 가중합과 구부리기를 여러 층 겹치면, 꺾인 규칙을 여러 개 이어 붙여 웬만한 모양을 근사할 수 있습니다.

쉽게 말하면 · 자 하나로는 직선밖에 못 긋지만, 짧은 자를 여러 개 꺾어 이으면 곡선도 따라 그릴 수 있어요.

여기서 한 번 멈춰도 괜찮아요. "층을 겹치면 꺾인 선을 이어 붙인다" — 이 한 문장이면 충분합니다.

모아 · "z = Σwx + b… 저 뾰족한 E 같은 건 뭐예요? 읽는 법부터 알려 주세요!"

학교 수학으로 보면 · 일차함수 y = ax + b를 입력 여러 개로 늘린 것 (5장 연결표: 신경망 = 합성함수)

z = w₁x₁ + w₂x₂ + b   →   ŷ = f(z)
조각읽는 법 · 뜻
Σ"시그마". 여러 개를 모두 더하라는 기호. 여기서는 w₁x₁ + w₂x₂를 줄여 쓴 것
wᵢ"더블유 아이". i번째 입력의 중요도(가중치). 학습으로 정해짐
b"비". 편향. 그래프를 위아래로 옮기는 값
f(z)"에프 오브 제트". 활성화 함수에 z를 넣은 값
숫자로 한 번 해 보기
  1. 입력 x₁ = 1, x₂ = 2, 가중치 w₁ = 0.6, w₂ = 0.2, 편향 b = −0.5
  2. 가중합 z = 0.6×1 + 0.2×2 − 0.5 = 0.6 + 0.4 − 0.5 = 0.5
  3. ReLU라면 f(0.5) = 0.5 (양수는 그대로)
  4. 시그모이드라면 f(0.5) = 1 ÷ (1 + e−0.5) ≈ 0.622

모아 · "곱하고 더하고, 함수 하나에 넣으면 끝이네요. 아래 조립대에서 직접 돌려 볼게요!"

일상으로 치면입사 지원서 평가와 같아요. 경력·자격증·면접 점수에 각각 비중을 곱해 더하고(가중합), "합격선을 넘었나"로 한 번 걸러요(활성화). 심사위원이 여러 단계면 층이 여러 개인 셈이에요.
현장에서는통신사의 해지 예측, 카드사의 이상 거래 점수, 부동산 가격 예측처럼 표로 된 데이터에 씁니다. 다만 표 데이터만 있다면 트리 계열 모델이 더 잘 맞는 경우도 많아서, 둘을 같이 비교해 봐요.

하루의 보고 · 처음 값(x₁=1, x₂=2, w₁=0.6, w₂=0.2, b=−0.5)에서 z = 0.5, ReLU 출력 0.5, 시그모이드 출력 0.622예요. 위의 손계산과 같아요.

박사의 해석 · 시그모이드 0.622는 "해지할 확률을 62%쯤으로 본다"는 뜻으로 읽습니다. 그런데 '선형'을 고르면 그래프가 곧은 선이라, z가 커지면 출력도 끝없이 커집니다. 확률이 1을 넘는 이상한 답이 나오는 거죠. 그래서 확률을 낼 때는 마지막에 시그모이드를 씁니다.

08이 설계의 한계 → 다음 도면

한계 1 · 기억이 없다 — 입력 하나를 따로 봅니다. "어제 매출 → 오늘 매출"처럼 순서가 중요한 데이터는 03 RNN 도면이 필요해요.
한계 2 · 위치를 모른다 — 사진을 숫자 한 줄로 펴서 넣으면 "옆 픽셀끼리 붙어 있다"는 정보가 사라집니다. 그래서 02 CNN 도면이 나왔어요.
한계 3 · 부품이 금방 많아진다 — 모든 뉴런을 서로 다 잇기 때문에 입력이 크면 가중치가 폭발적으로 늘어납니다.
정리 · FNN은 ① 곱해서 더하고 ② 구부리기를 층마다 되풀이하며, 신호는 앞으로만 흐릅니다. 학습은 예측과 정답의 차이를 줄이도록 가중치를 고치는 일입니다.
