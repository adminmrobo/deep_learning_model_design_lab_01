01연습장 쓰는 법

① 의뢰서 고르기위쪽 탭에서 현장 하나를 고릅니다. 주소 끝에 #photo, #call, #vibe, #rare를 붙이면 그 의뢰서가 바로 열려요.
② 조건 바꾸고 설계도 고르기초록 조작판은 현장 조건, 파란 단추는 내 결정입니다. 막대 그래프가 설계도마다의 적합도를 보여 줘요.
③ 미션 세 개가장 맞는 설계도 찾기 · 함정 살펴보기 · 조건을 바꿔도 결론이 유지되는지 확인. 조작해야 통과 표시가 켜져요.

적합도 점수는 아홉 도면의 내용을 바탕으로 만든 교육용 예시 값입니다. 실제 모델 성능을 잰 숫자가 아니며, 실제 프로젝트에서는 같은 데이터로 직접 시험해 비교해야 해요.

03네 의뢰서가 함께 묻는 것

네 현장 모두에서 "가장 크고 새로운 설계도"가 늘 이기지는 않았습니다. 사진이 적으면 CNN이, 문장이 짧으면 GRU가, 정답표가 없으면 오토인코더가 앞섰어요. 그리고 조건이 바뀌면(사진이 아주 많아지면, 정답이 쌓이면, 종류가 많아지면) 1등도 바뀌었죠. 설계도를 고르는 일은 데이터 모양 → 목적 → 데이터 양·정답 유무·자원 순서로 좁힌 뒤, 후보 두세 개를 같은 데이터로 시험하는 일입니다.
이 연습장의 한계 — 적합도는 아홉 도면의 설명을 규칙으로 옮긴 교육용 예시 값이고, 조건도 하나씩만 바꿔 볼 수 있게 단순하게 만들었습니다. 실제 성능은 데이터 품질, 모델 크기, 학습 설정에 따라 크게 달라져요. 경영·투자 판단의 근거로 쓰지 마세요.
